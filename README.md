# 名古屋クアトロ前 食事・昼飲み候補

GitHub Pages向けの静的HTMLです。

## 公開方法
1. この `index.html` をGitHubリポジトリのルートに置く
2. GitHub → Settings → Pages
3. Source: Deploy from a branch
4. Branch: `main` / `/ (root)`
5. Save

## 構成
- `index.html` のみで動作
- Leaflet + OpenStreetMapをCDN利用
- 店舗30件のカード一覧
- カテゴリフィルター
- 店名・名物検索
- 店舗ピン
- アーバンクア（S）と名古屋クラブクアトロ（G）の位置表示

## Codexへ引き継ぐ場合
このリポジトリをCodexで開き、`index.html`を編集対象として指定してください。
